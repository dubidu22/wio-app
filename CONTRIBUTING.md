# Contributing

Thank you for your interest in wio-app.

## Outside contributions

Outside contributions need a signed contributor licence agreement (CLA) before they can be merged. The agreement and the check that enforces it are not set up yet, so **pull requests from outside contributors cannot be merged for now**. Issues with bug reports and ideas are welcome.

## How work is done here

- Every change goes through an issue, a written plan, a pull request and a review; `main` is protected and merged by squash only.
- Code, identifiers, comments, issues and pull requests are in English. User interface text is German first and lives only in translation (ARB) files.
- Never commit customer data, real addresses, credentials or tokens. Examples use invented people and places.
- Pull request title: `<area>: <outcome> (#issue)`. Body: what changed, tests run with counts, risk, what is out of scope, screenshots at 390 × 844 for UI changes.

## Licence of contributions

By contributing you agree that your contribution is licensed under `AGPL-3.0-only`. Once the CLA exists, outside contributions are accepted only after it is signed.
